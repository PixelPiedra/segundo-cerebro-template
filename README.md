# 🧠 Segundo Cerebro — Plantilla de Vault Obsidian

Vault de Obsidian para **seguimiento de proyectos Serfe/HolaSim** con captura, planificación, registro de horas y revisión.

Basado en **PARA + Zettelkasten + MOC**, con paneles dinámicos y diagrama Gantt diario.

---

## 🏁 ¿Nunca usaste Obsidian?

Empezá por acá: [`90_Admin/Onboarding Obsidian.md`](90_Admin/Onboarding%20Obsidian.md)

---

## 🚀 Inicio Rápido

```bash
git clone <este-repo> segundo-cerebro
obsidian segundo-cerebro
```

1. **Configuración → Community plugins → Activar**
2. Instalá: **Dataview**, **Templater**, **Meta Bind**, **Buttons**
3. Andá al **`Dashboard.md`**
4. Leé la **`90_Admin/Guía del Vault.md`**

> ⚠️ Si ves bloques `dataviewjs` sin renderizar o botones que no funcionan, falta algún plugin.

---

## ✨ Funcionalidades

| Seguimiento de Proyectos | Gestión de Conocimiento |
|---|---|
| Plan de Desarrollo | MOCs dinámicos |
| Bitácora de Ejecución | Distill (resumen progresivo) |
| Resumen de Horas (recursivo) | Conexiones curadas entre notas |
| Gantt del Día | Notas Diarias + Revisión Semanal |
| Subtareas recursivas | Esperando + Algún día/Tal vez (GTD) |
| Panel de Control (metadatos) | Archivo por estado / Express |
